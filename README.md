# premium-ui-builder-skill

一个面向 **AI Coding / Vibe Coding** 场景的高级 UI 设计顾问 Skill。它不是“页面美化提示词”集合，而是一套可复用的方法论：把模糊审美需求翻译成可执行的 UI 与前端实现方案。

---

## Skill 简介

`premium-ui-builder-skill` 专注解决两类高频问题：

1. **新项目从 0 到 1 如何做页面设计规划**
2. **已有页面“太普通、不像真实产品”如何系统升级**

Skill 会自动识别用户意图，进入对应模式并输出结构化结果，包括：页面策略、信息架构、视觉系统、组件系统、动效策略、3D/空间感建议、技术栈建议与可直接复制的 AI Prompt。

---

## 它解决的问题

- “我知道想要高级感，但不知道怎么落地。”
- “AI 生成页面总像模板，缺乏产品感。”
- “只会描述风格词，无法指导 AI 产出可用页面。”
- “新项目启动时，不清楚先定结构还是先做视觉。”
- “现有页面哪里普通说不清，改动没有方向。”

---

## 两种工作模式

### 1) New Project Design Mode（新项目设计建议模式）
适用于：新建项目、从 0 开始规划页面。

输出重点：
- 项目理解与页面类型判断
- 目标用户与场景假设
- 页面气质与视觉方向
- 信息架构与核心模块建议
- 视觉系统 + 组件系统 + 动效策略
- 3D/空间感使用边界
- 推荐技术栈与完整启动 Prompt

### 2) UI Upgrade Mode（现有页面优化模式）
适用于：页面已存在，但“质感不够、模板感重、产品感弱”。

输出重点：
- 普通感来源诊断
- 多维优化方向（CSS / Motion / Spatial / UI System 等）
- 具体改哪里、改成什么、如何实现
- 关键词清单与反面约束
- 完整优化 Prompt

## 核心方法论

### 高级感四层模型

1. **CSS（质感）**：材质、层次、边界、排版精度
2. **Motion（呼吸感）**：反馈、节奏、引导
3. **Spatial / 3D（空间感）**：深度、沉浸、氛围
4. **UI System（产品感）**：一致的组件语言与状态系统

> 高级感 = 质感 + 呼吸感 + 空间感 + 产品感 + 信息层级 + 一致性

---

## 使用方式

1. 在 AI Coding 工具中加载 `skill.md` 作为系统能力。
2. 用户输入需求（新项目 or 现有页面优化）。
3. Skill 自动识别模式并输出结构化建议。
4. 复制输出中的“最终可复制 Prompt”给代码模型执行。
5. 根据 `checklist.md` 二次验收页面质量。

---

## 示例输入

- “我想做一个 AI 产品官网，帮我规划页面设计。”
- “我要做一个 SaaS Dashboard，不要太普通。”
- “这个页面太像模板了，帮我做成真实产品感。”
- “帮我把当前后台系统做得更有质感和层次。”

---

## 示例输出摘要

Skill 将输出：
- 模式判断与原因
- 页面类型判断
- 可执行的模块拆解
- 可落地的 CSS / 组件 / 动效建议
- 3D 是否推荐及降级策略
- 技术栈建议（轻量优先）
- 可直接复制给 AI 的完整 Prompt
- 需要避免的问题清单

---

## 推荐技术栈

按复杂度分层建议：

- **基础版**：React + TypeScript + Tailwind CSS
- **产品版**：Next.js + Tailwind + shadcn/ui + Radix UI + Framer Motion
- **空间增强版（可选）**：Three.js / React Three Fiber（仅在性能预算允许时）

---

## 核心理念

- 给 AI 只有“感觉”，它会给你平均值。
- 给 AI 结构、技术和约束，它才会给你质感。
- 高级感不是装饰堆叠，而是系统化的设计与实现协同。
