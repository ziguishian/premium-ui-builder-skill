## 中文简介

`premium-ui-builder-skill` 是一个面向 AI Coding / Vibe Coding 的高级 UI 设计顾问 Skill。
它的目标是把“页面不够高级 / 太普通 / 像模板”这类模糊审美描述，转化为**可执行**的 UI 设计与前端实现方案。

### 解决的问题
- 新项目从 0 到 1：不知道先做信息架构还是视觉系统。
- 现有页面升级：知道“不高级”，但无法定位问题和改造路径。
- AI 出图/出代码偏模板化：缺少结构、约束与实现边界。

### 双模式能力
1. **New Project Design Mode**
   - 项目理解、页面类型判断、信息架构规划
   - 视觉系统 / 组件系统 / 动效策略
   - 3D 使用边界 + 技术栈建议 + 可复制启动 Prompt

2. **UI Upgrade Mode**
   - 普通感来源诊断（层级、留白、组件、色彩、动效）
   - 分维度优化（CSS / Motion / Spatial / UI System）
   - 逐模块“改哪里、改成什么、如何实现、删减什么”
   - 可复制优化 Prompt + 禁止项

### 核心方法论
高级感四层模型：
- **CSS（质感）**
- **Motion（呼吸感）**
- **Spatial / 3D（空间感）**
- **UI System（产品感）**

> 高级感 = 质感 + 呼吸感 + 空间感 + 产品感 + 信息层级 + 一致性

### 推荐目录（Skill 标准）
- `SKILL.md`：技能入口（触发 + 执行指令）
- `scripts/`：可执行脚本（可选）
- `references/`：文档与规范（可选）
- `assets/`：模板资源（可选）
- `agents/openai.yaml`：展示和策略（可选）

## English Overview

`premium-ui-builder-skill` is an AI-first UI design consultant skill for AI Coding / Vibe Coding workflows.
It converts vague aesthetic feedback like “too ordinary,” “template-like,” or “not product-grade” into **actionable** UI and front-end implementation guidance.

### What it solves
- 0→1 project kickoff: unclear design direction and system planning.
- Existing page upgrades: unclear diagnosis and execution path.
- Template-like AI output: missing structure, constraints, and implementation boundaries.

### Two Operating Modes
1. **New Project Design Mode**
   - Project understanding and page-type classification
   - Information architecture + visual system + component system
   - Motion strategy, 3D boundaries, stack recommendation, copy-ready prompt

2. **UI Upgrade Mode**
   - Diagnose why a page looks generic
   - Optimize by CSS / Motion / Spatial / UI System dimensions
   - Module-level refactor instructions: what to change and how to implement
   - Copy-ready optimization prompt + explicit anti-pattern constraints

### Core Method
Premium UI 4-layer model:
- **CSS** (material quality)
- **Motion** (breathing feedback)
- **Spatial/3D** (depth)
- **UI System** (product consistency)

### Professional Principle
If you only give AI “vibe words,” it returns average output.
If you give AI structure, constraints, and implementation rules, it can deliver premium results.
