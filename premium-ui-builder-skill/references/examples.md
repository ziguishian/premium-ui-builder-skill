## 示例 1（新项目）
### 用户输入
我想做一个 AI 产品官网，帮我规划页面设计。

### 模式判断
**New Project Design Mode**（关键词：“想做”“官网”“规划页面设计”）

### Skill 分析
- 页面类型：AI 产品官网（主）+ Landing Page（次）
- 建议气质：科技感、专业、克制、产品感
- 核心模块：Hero / 产品能力 / 工作流演示 / Use Cases / Pricing / FAQ / CTA

### 最终可复制 Prompt
请为一个 AI 产品官网设计并实现高端 Landing Page。使用 Next.js + TypeScript + Tailwind CSS + shadcn/ui。页面包含 Hero、核心能力、交互式工作流演示、应用场景、定价、FAQ、CTA。视觉上采用深浅对比与克制发光，使用 subtle border、soft shadow、layered surfaces 构建层次。动效采用 Framer Motion，实现 hover feedback、scroll reveal、stagger entrance，时长控制在 0.3s-0.6s。允许在 Hero 背景加入轻量 gradient mesh 或粒子氛围，但不得抢主体文案，移动端降级为静态背景。输出要求：组件化结构、响应式、包含空状态与加载态样例、代码可直接运行。

**New Project Design Mode**

## 示例 5（优化）
### 用户输入
这个页面不够高级，帮我优化一下。

### 模式判断
**UI Upgrade Mode**（关键词：“这个页面”“不够高级”“优化”）

### Skill 分析
- 常见问题假设：层级平、留白挤、组件不统一、缺反馈
- 优化方向：先系统后装饰，优先改信息与组件规则

### 最终可复制 Prompt
请对现有页面进行高级感重构，目标是从“模板感”升级为“真实产品感”。先诊断并重构信息层级：明确主次视觉锚点，增加合理留白，减少无效装饰。统一组件系统（按钮、卡片、输入、标签、弹窗）并补齐状态（hover/focus/loading/empty/error）。CSS 使用 subtle border + soft shadow + 分层背景，避免重渐变与过曝发光。动效只保留交互反馈与局部过渡。请以不改核心业务功能为前提输出优化后的页面代码与改动说明。

## 示例 6（优化）
### 用户输入
页面太像模板了，怎么改得更像真实产品？

### 模式判断
**UI Upgrade Mode**

### Skill 分析
- 模板感来源：区块堆砌、组件无规则、状态缺失
